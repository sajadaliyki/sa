# یوک — بازسازی کامل

این پروژه Android از صفر ساخته شده و به APKهای NativeActivity قبلی وابسته نیست.

## لانچر
- نام برنامه: یوک
- Activity اصلی: ir.yook.game.MainActivity
- آیکون: Y
- Legacy icon: دارد
- Round icon: دارد
- Adaptive icon: دارد
- Monochrome icon: دارد
- دیگر `android.app.NativeActivity` وجود ندارد.

## بازی
- صفحه اول بدون کادر سفید
- دکمه: «شروع مسابقه»
- ۲ تا ۱۰ تیم
- تایمر با درست/رد ریست نمی‌شود
- تایمر بعد از زدن «برای شروع روی دکمه بزنید» شروع می‌شود
- گزینه مشهدی حذف شده
- موضوع «گویش سبزواری» و بانک معنی‌های فارسی آن حفظ شده
- بانک ۵۰۰ حیوان حفظ شده
- آفلاین

## ساخت APK
1. Android SDK Platform 35 و Build Tools را نصب کنید.
2. روی `BUILD_APK.bat` دوبار کلیک کنید.
3. در پایان فایل `Yook.apk` کنار BAT ساخته می‌شود.
